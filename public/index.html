How it works

1

Fork the repository

Fork the dev-cv.in repository to your GitHub account.

2

Create your request

Add your subdomain request as a JSON file inside the requests/ directory.

3

Commit and create a Pull Request

Commit your JSON file and open a pull request against the main repository.

4

Validation & review

GitHub Actions validates your request. The repository owner reviews the pull request.

5

DNS goes live

After approval and merge, DNS automation creates your subdomain.
