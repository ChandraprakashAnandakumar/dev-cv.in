# dev-cv.in

Free developer subdomains powered by GitHub and Cloudflare.

## 🚀 Get Your Free Subdomain

Want a free subdomain like:

`yourname.dev-cv.in`

Follow these steps.

### 1. Fork this repository

Fork this repository to your GitHub account.

### 2. Create your request

Copy:

`requests/templates/request-template.json`

Create:

`requests/YOUR_GITHUB_USERNAME.json`

### 3. Fill in your details

Example:

```json
{
  "github_username": "yourusername",
  "subdomain": "yourname",
  "target": {
    "type": "CNAME",
    "value": "example.github.io"
  },
  "project": {
    "name": "My Portfolio",
    "description": "My personal developer portfolio"
  },
  "terms": "Y"
}
